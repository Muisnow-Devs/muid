# Unaccomplished MuID “new” backend

> This repository is preserved for reference and educational purposes, including for anyone interested in seeing how the site was previously designed and implemented.

Originally, this was a replacement for the MuID project. But after building this project for a while, it seems to be unmaintainable for an indie developer. I made it too big for me to keep going.

As a result, I canceled the plan. Transferring the old MuID infrastructure into a Logto-based infrastructure. So, this project should no longer be maintained. Now, it's a public archive, [as I promised](https://x.com/Hen000000hen/status/2079132927875846364?s=20).
